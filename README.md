# Asteroids.c
A complete arcade-style space shooter built from scratch in C using the raylib library. The player controls a ship, shoots lasers at asteroids that break into smaller pieces, and fights enemy UFOs. Includes a start menu, game-over screen, score system and sound effects.
## Features
- Player ship with lasers
- Asteroids that break into smaller pieces
- Enemy UFOs
- Start menu and game-over screen
- Score system and sound effects

## Built With
- C
- raylib

## How to Run
1. Install raylib
2. Compile: gcc asteroids.c -o asteroids -lraylib -lopengl32 -lgdi32 -lwinmm
3. Run: asteroids.exe

## Controls
- [Key]: Move
- [Key]: Shoot
